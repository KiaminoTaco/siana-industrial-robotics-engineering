# Project Contributions and Scope of Responsibility

## 1. Team project

SIANA is a multidisciplinary engineering project. Mechanical design, electrical engineering, embedded control, software, AI, inspection and system integration are interconnected team activities.

## 2. Primary individual responsibility

The principal individual responsibility represented in this repository is the **electrical part**.

This includes the integration of motors and sensors and their connection to the software control layer.

## 3. Software integration

The electrical/control contribution extends into the Python/Arduino software because the physical devices cannot be considered independently from their control interfaces. The relevant work therefore includes mapping application commands to actuator behavior and bringing sensor data into the software layer.

## 4. Robot Control Interface

The dedicated Robot Control Interface was developed collaboratively with the teammate responsible for the AI component.

The contribution represented here is the hardware-oriented side of that collaboration: integration of motors, sensors and embedded control with the interface software.

## 5. Mechanical and AI work

Mechanical and AI work is retained as project-level material. Where supporting contributions were made, they should be described as integration/research support rather than as sole authorship.
