# Reference Material

The repository contains the project software package and selected supplied reference assets.

The following categories were considered during consolidation:

- global technical report;
- electrical engineering report;
- mechanical engineering package;
- maintenance material;
- Robot Control Interface material;
- SIANA APP software package;
- project specification/cahier des charges;
- system architecture material.

The original mechanical and electrical design assets are intentionally not duplicated here because the requested final repository keeps those design files available for manual addition under `hardware/`.
